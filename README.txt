OPERATIONS REPORTING DASHBOARD

How to use
1. Extract all files into one folder.
2. Open index.html in Chrome or Microsoft Edge.
3. Keep internet available so the Excel reader library can load.
4. Click Import Excel and select a workbook matching Reporting_Template.xlsx.
5. Select YTD or Selected month and choose a month.

Template rules
- Keep the first worksheet layout and the 12 month columns.
- Keep these row labels unchanged: Total Staff HCs, Total Working Hours log count, Working Hour/Staff, Working Hours by Segment, Job Requests by Segments, Job Requests by Type, Total JRs Received.
- Values may be updated freely.

All imported workbook data is processed locally in the browser.
